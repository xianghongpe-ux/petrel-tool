## 一、什么是校园社区？

校园社区（Campus Chapter）是海燕党在高校中的基层单位。不同于传统学生社团的"指导老师-主席-部长"金字塔结构，海燕党校园社区完全遵循去中心化治理协议。

**核心原则：**

- **自主成立** — 任何高校的 5 名以上学生即可发起成立
- **平等投票** — 每位成员一票，不设干部特权
- **直接民主** — 重要决策由全体成员投票决定
- **开放连接** — 可自由加入/退出，也可与其他高校社区联动
- **算力共享** — 校园节点可接入 DZN 网络，贡献学生闲置算力

## 二、如何启动一个校园社区？

### 第一步：找到你的队友

> 一个人可以走得很快，一群人才能走得更远。

你需要至少 **3 名联合发起人**（建议 3-5 人）。以下渠道可以帮助你找到志同道合的同学：

| 渠道 | 方法 | 建议 |
|------|------|------|
| 校内论坛 | 发布招募帖 | 侧重技术/治理/创新话题 |
| 课程群 | 寻找计算机/政治学/社会学同学 | 跨学科组合更佳 |
| 开源社团 | 联系已有的技术社团 | 寻求合作而非竞争 |
| 导师推荐 | 找对去中心化技术感兴趣的教授 | 可获得场地等资源支持 |

### 第二步：确定社区定位

校园社区可以有多种定位，选择最适合你校情况的：

1. **技术型** — 侧重 DZN 节点运维、贡献算力、参与协议开发
2. **研究型** — 侧重去中心化治理理论、社会学实验
3. **推广型** — 侧重新成员教育、举办讲座和开放日
4. **综合型** — 兼顾技术、研究和推广

> 💡 **建议新生社区从推广型起步**，先积累成员，再逐步向技术型演进。

### 第三步：发起成立

满足以下条件即可正式成立校园社区：

1. 至少有 **5 名成员**（含联合发起人）
2. 拟定社区名称（格式：`海燕党·XX大学分会`）
3. 确定一名"临时召集人"（相当于联系人，非领导）
4. 向海燕党社区登记处提交注册申请

**登记模板：**

```json
{
  "community_name": "海燕党·北京大学分会",
  "university": "北京大学",
  "founding_members": 8,
  "primary_domain": "综合型",
  "contact": "wechat_id_or_email",
  "declaration": "我们认同海燕党去中心化治理理念，自愿成立校园社区。"
}
```

提交方式：使用 `community_split.py` 的注册功能，或直接联系社区管理员。

### 第四步：第一次会议

建议第一次线下会议完成以下事项：

1. 相互认识（破冰活动）
2. 集体阅读《创世铭文》(GENESIS.md)
3. 讨论社区半年目标（3-5 条）
4. 选举第一轮"议题协调人"（非永久职位，每月轮换）
5. 确定下次会议时间和议题

## 三、校园社区运营指南

### 3.1 治理结构

校园社区采用**扁平化治理**，不设永久主席：

| 角色 | 职责 | 任期 |
|------|------|------|
| 议题协调人 | 组织会议、整理提案 | 1 个月（轮换） |
| 技术联络人 | 对接 DZN 网络、维护节点 | 自愿 |
| 活动策划人 | 组织线下活动 | 按活动轮换 |

所有角色的权力来源于**社区成员的共识委托**，而非职务本身。

### 3.2 决策机制

- **日常事务**：协调人自行决定，事后报备
- **重要事项**（如支出、合作）：发起提案，全员投票 >60% 通过
- **重大事项**（如修改社区规则）：发起提案，全员投票 >75% 通过
- **紧急事项**：协调人先行处理，24 小时内补办投票

### 3.3 分裂与扩容

当校园社区成员超过 **150 人** 时（Dunbar's Number），应启动自动分裂流程：

```bash
# 使用 community_split.py 自动处理
python community_split.py --check
# 检测到溢出后生成分裂提案
# 社区投票 -> 执行分裂 -> 两个子社区继承全部上下文
```

分裂后两个子社区分别为：
- `海燕党·XX大学甲部`
- `海燕党·XX大学乙部`

两社区保持合作关系，共享基础设施（如 DZN 节点）。

### 3.4 友好分叉

如果部分成员对社区方向有根本性分歧，不应压制不同意见，而应启动友好分叉：

```bash
# 使用 fork_toolchain.py 进行友好分叉
python fork_toolchain.py --demo
```

分叉出去的社区仍然是海燕党生态的一部分，可以：
- 通过跨仓提案(cross-fork PR)回流贡献
- 共享 DZN 网络资源
- 参与跨社区活动

## 五、常见问题

### Q: 学校不承认怎么办？

校园社区是开放协议网络的一部分，**不需要学校官方承认**即可运作。协议网络的设计初衷就是不依赖任何中心化权威。但我们也建议：

- 如果学校有区块链/开源社团，尝试合作而非对抗
- 使用学校公共空间（图书馆讨论室、咖啡厅）作为活动场所
- 技术和开源活动通常比政治类活动更容易被接受

### Q: 成员数量太少怎么办？

从 **5 人核心团队** 起步，专注以下策略：

1. **价值展示** — 做一个能实际运行的 DZN 节点
2. **低门槛参与** — 举办"零基础 DZN 节点搭建"工作坊
3. **跨社群联动** — 邀请校内技术社团联合举办活动
4. **成果输出** — 将社区讨论成果整理成文章发布

### Q: 如何与总社区保持联系？

- 每周提交社区简报（模板见下方）
- 重要提案同步到主社区投票
- 参与跨叉提案回流
- 参加季度性的跨社区线上会议

**简报模板：**
