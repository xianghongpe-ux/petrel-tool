## 🚀 7 天开班计划

### 第 1 天：筹备

- [ ] 确定社区定位（技术/治理/研究）
- [ ] 选定通信工具（Telegram / Matrix / Discord）
- [ ] 创建初始频道：#公告 #技术讨论 #节点运营 #反馈
- [ ] 指定 3 名初始协调员

### 第 2 天：基础设施

- [ ] 至少 3 人部署 DZN 推理节点
- [ ] 验证节点间 P2P 通信
- [ ] 运行一轮共识测试
- [ ] 确认社区健康看板在线

### 第 3 天：规则制定

- [ ] 起草社区章程（参考模板）
- [ ] 确定声誉评分规则
- [ ] 确定投票门槛（最低签名数/通过比例）
- [ ] 社区投票通过初始规则

### 第 4 天：开源

- [ ] 从种子 U 盘复制协议种子
- [ ] 在 GitLab/Codeberg/Gitee 创建镜像仓库
- [ ] 发布第一篇社区公告
- [ ] 开放节点注册

### 第 5 天：扩展

- [ ] 邀请 ≥5 名新志愿者部署节点
- [ ] 组织首次社区贡献者会议
- [ ] 第一轮声誉评分数据落地

### 第 6 天：运行

- [ ] 社区自行运行至少 3 轮投票
- [ ] 提交首次社区提案
- [ ] 周报发布

### 第 7 天：自持

- [ ] 确认社区可脱离原始引导组独立运行
- [ ] 评估是否加入海燕党主网
- [ ] 生成社区创世区块

## 📊 社区心电图看板

> 一个单 HTML 文件的社区健康度实时看板，部署在任意节点的 `:9103` 端口。

### 指标说明

| 指标 | 健康范围 | 警告范围 | 危险范围 |
|------|----------|----------|----------|
| 在线节点数 | ≥5 | 2-4 | ≤1 |
| 共识分数 | ≥0.8 | 0.5-0.79 | <0.5 |
| 活跃提案 | 1-5 | 6-10 | >10 或 =0 |
| 投票参与率 | ≥60% | 30-59% | <30% |
| 熔断状态 | normal | recovering | tripped |
| 节点衰减率 | <5%/月 | 5-20%/月 | >20%/月 |

## 🌡️ 社区健康评分公式

```
HealthScore = W1 * (online_nodes / max_nodes)
            + W2 * consensus_score
            + W3 * min(vote_participation, 1.0)
            + W4 * (1 - fuse_events / max_fuse)
            + W5 * (1 - node_decay_rate)

权重:
  W1 = 0.25  (网络规模)
  W2 = 0.25  (共识健康)
  W3 = 0.20  (治理参与)
  W4 = 0.15  (熔断状态)
  W5 = 0.15  (节点留存)

健康阈值:
  ≥0.80: 🟢 优秀
  ≥0.60: 🟡 良好
  ≥0.40: 🟠 需关注
  <0.40: 🔴 危机
```

## 🆘 常见问题

**Q: 我只有一台旧笔记本电脑，可以运行节点吗？**
A: 可以。DZN 推理节点自动检测硬件，CPU 模式仅需 4GB 内存即可运行。

**Q: 需要懂多少技术？**
A: 会使用终端 + Docker 即可。部署脚本是一键式的。

**Q: 运行节点有什么好处？**
A: 获得声誉分 → 参与治理投票 → 影响网络发展方向。算力贡献越多，话语权越大。

**Q: 节点需要 24h 在线吗？**
A: 不需要。离线节点会自动暂停任务分配，重新上线后恢复。
