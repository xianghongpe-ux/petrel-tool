# HY Token · 海燕党经济模型白皮书

## 概述

HY Token 是海燕党（PETREL AI PARTY）协议的治理与经济激励Token。设计目标：驱动节点运行、激励社区贡献、防止女巫攻击、保障治理质量。

## 核心参数

| 参数 | 值 |
|------|------|
| 发行总量 | 100,000,000 HY（1亿） |
| 区块链 | Ethereum (Sepolia → 主网) |
| 合约标准 | ERC-20 + ERC-5805 (治理) |
| 精度 | 18位小数 |
| 释放周期 | 4年线性释放，无预挖 |

## 分配方案

| 分配对象 | 比例 | 数量 | 释放规则 |
|---------|:----:|:----:|---------|
| 🌱 社区激励 | 50% | 50,000,000 | 4年线性释放，每月约104万 |
| 👨‍💻 创始团队 | 20% | 20,000,000 | 2年Cliff+2年线性 |
| 🏦 治理金库 | 20% | 20,000,000 | 社区提案控制，5/9多签 |
| 🌍 生态基金 | 10% | 10,000,000 | 开发者资助+社区黑客松 |

## 治理权重公式

```
治理权重 = min(staked_HY, 总Stake * 2%) × 声誉系数 × 时间乘数

其中：
- staked_HY = 质押的HY数量
- 总Stake * 2% = 反寡头上限（任何成员不超过总质押的2%）
- 声誉系数 = log2(1 + SBT声誉分) / 10（范围0.1-1.0）
- 时间乘数 = 1 + 质押天数 × 0.001（最高2.0）
```

## 链上声誉绑定

声誉系统通过不可转让的 SBT（Soulbound Token）实现：

| 声誉维度 | 权重 | 数据源 |
|---------|:----:|--------|
| 代码贡献 | 25% | GitHub PR/Commit |
| 治理参与 | 20% | 提案/投票记录 |
| 社区运营 | 15% | 活动组织/参与 |
| 课程学习 | 15% | 课程完成证明 |
| 翻译贡献 | 10% | 多语言翻译量 |
| 审计贡献 | 10% | 安全审计报告 |
| 其他 | 5% | 社区自治决定 |

## 通胀模型

- 前4年：每年通缩（Staking奖励来自分配储备）
- 第5年起：每年最高2%通胀，由治理投票决定
- 金库收入（服务费/捐赠）定期回购销毁
