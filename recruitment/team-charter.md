# 海燕党核心团队工作章程

> 政党名称：**海燕党** ｜ 英文名称：**PETREL AI PARTY** ｜ 创始人：**刘海燕（LIU HAIYAN）**

---

## 1. 团队定位

核心团队是海燕党开源协议网络的**初始开发和维护者集体**，不是权力机构。核心团队的最终目标是**让自己变得不再必要**——将维护权逐步移交给由社区选举产生的多签持有人委员会。

## 2. 团队构成

首批 8-12 人，按以下角色分配：
- 协议架构师 1-2人
- 密码学工程师 2人
- 分布式系统工程师 2人
- AI 工程师 2人
- 前端/全栈工程师 1人
- 内容/课程设计师 2人
- 法律顾问 1-2人（外部）

## 3. 工作机制

### 3.1 双周公开例会
- 每两周一次线上公开会议
- 议程：进度回顾 + 阻塞项讨论 + 下周计划
- 会议纪要（脱敏后）公开至 GitHub Discussions

### 3.2 公开路线图看板
- 全部里程碑通过 GitHub Projects 公开管理
- 任何人可查看当前进度
- 里程碑完成自动触发社区通知

### 3.3 决策机制
- 技术决策：RFC 流程（GitHub Issues 模板）
- 人事决策：核心团队内部共识
- 协议级决策：必须经过社区提案流程（Phase 1 后启用）

## 4. 贡献者权益与义务

### 权益
- 链上贡献声誉记录
- 创始贡献者永久署名
- 参与协议架构演进的关键讨论

### 义务
- 每周 ≥10 小时有效贡献
- 参与双周例会和代码评审
- 遵守行为准则（Code of Conduct）

## 5. 退出机制

- 任何核心成员可随时自愿退出
- 连续 4 周无有效贡献视为自动退出
- 退出不影响已有贡献记录

## 6. 团队向社区过渡

当满足以下条件时，核心团队启动向社区治理过渡：
- 节点社区 ≥100 个
- 外部贡献者 PR 合并数 ≥核心团队 PR 数
- 社区发起并通过过渡提案
