# 核心贡献者招募

## 🏛️ 关于海燕党

**海燕党（PETREL AI PARTY）** 是一个以开源、去中心化、AI 民主化为
核心理念的技术社区党。我们致力于：

- 构建开放、透明、不可篡改的开源基础设施
- 推动 AI 技术的民主化与大众化
- 建立代码即治理、贡献即权力的工程文化
- 通过区块链与分布式系统技术确保代码的永久存证

> **"开发过程本身就是传播。"** 全部代码开源、全部设计文档公开、
> 全部里程碑开放看板——我们的工程文化就是最好的招募说明。

---

## 🎯 招募目标

首批组建 **8-12 人核心贡献者团队**，覆盖以下关键领域：

| 角色 | 人数 | 职责 |
|------|------|------|
| 协议架构师 | 1-2 | 设计核心协议框架与治理机制 |
| 密码学工程师 | 1-2 | 实现零知识证明、数字签名、哈希锚定 |
| 分布式系统工程师 | 1-2 | 建设 P2P 网络、共识机制、存储层 |
| 智能合约开发者 | 1-2 | 开发 Solidity 合约、铭文系统、DAO 治理 |
| DevOps/SRE | 1 | CI/CD 流水线、镜像同步、基础设施维护 |
| 安全审计员 | 1 | 代码审计、威胁建模、漏洞发现 |
| 前端/全栈开发者 | 1 | 去中心化治理面板、社区工具开发 |
| 技术写作者 | 1 | 协议规范文档、RFC、技术白皮书 |

## 📋 角色要求

### 1. 协议架构师

**必备技能：**
- 6 年以上分布式系统或区块链协议设计经验
- 精通 Paxos/Raft、PBFT、HotStuff 等共识算法
- 有 Layer 1 / Layer 2 协议设计经验
- 熟悉 DAO 治理模型与代币经济学

**加分项：**
- 曾参与比特币/以太坊核心开发
- 发表过顶会论文（OSDI、SOSP、NSDI、CCS）
- 有开源社区治理经验

### 2. 密码学工程师

**必备技能：**
- 4 年以上密码学工程经验
- 精通椭圆曲线密码学、BLS 签名、零知识证明
- 有 MPC/TSS 实现经验
- 熟悉 SNARKs/STARKs 协议

**加分项：**
- 实现过完整的 zk-SNARK 验证器
- 参与过密码学标准制定
- 有后量子密码学研究背景

### 3. 分布式系统工程师

**必备技能：**
- 5 年以上分布式系统开发经验
- 精通 Go/Rust/C++ 中的至少两种
- 有 libp2p/IPFS 相关开发经验
- 理解 CAP 定理与最终一致性模型

**加分项：**
- 有 P2P 网络开发经验（Kademlia、DHT）
- 参与过 Filecoin/IPFS 核心开发
- 有高性能网络编程经验（io_uring、DPDK）

### 4. 智能合约开发者

**必备技能：**
- 3 年以上 Solidity 开发经验
- 精通 OpenZeppelin 库与 ERC 标准
- 有完整的智能合约安全审计经验
- 熟悉 Hardhat/Foundry 开发工具链

**加分项：**
- 发现过重大合约漏洞（CVE）
- 有 Layer 2 跨链桥开发经验
- 熟悉铭文协议（Ordinals、BRC-20、ARC-20）

### 5. DevOps/SRE

**必备技能：**
- 4 年以上 DevOps 经验
- 精通 GitHub Actions / GitLab CI
- 有 Docker/Kubernetes 生产运维经验
- 熟悉多平台镜像同步方案

**加分项：**
- 有 IPFS 节点运维经验
- 熟悉 Terraform/Ansible 基础设施即代码
- 有区块链节点运维经验

### 6. 安全审计员

**必备技能：**
- 4 年以上安全审计经验
- 精通 Web3/智能合约安全审计
- 熟悉 OWASP Top 10 与 MITRE ATT&CK 框架
- 有形式化验证工具使用经验

**加分项：**
- 有 Certik/Trail of Bits/OpenZeppelin 审计经验
- 发现过协议级安全漏洞
- 有审计自动化工具开发经验

### 7. 前端/全栈开发者

**必备技能：**
- 3 年以上前端开发经验
- 精通 React/Next.js/TypeScript
- 有 web3.js/ethers.js/viem 集成经验
- 有 DApp 前端开发经验

**加分项：**
- 有去中心化治理面板开发经验
- 熟悉 The Graph 子图开发
- 有 Wagmi/ConnectKit 集成经验

### 8. 技术写作者

**必备技能：**
- 3 年以上技术文档写作经验
- 精通中英双语技术文档撰写
- 有 RFC/规范文档编写经验
- 熟悉 Markdown/LaTeX/Docusaurus 工具链

**加分项：**
- 有开源项目文档维护经验
- 有区块链/Web3 技术背景
- 有技术白皮书撰写经验

## 📝 申请流程

### 第一步：提交贡献证明

请通过以下任一方式提交申请：

```bash
# 方式一：GitHub Issue
# 在 https://github.com/PetrelAIParty/petrel-ai-party-core 创建 Issue
# 标题格式：[Application] <角色> - <署名>

# 方式二：GPG 签名邮件
# 发送至：core-team@petrel-ai-party.org
# 所有邮件必须 GPG 签名
```

### 申请内容

请在申请中提供：

1. **个人简介**（包括开源贡献历史）
2. **与角色的匹配度说明**
3. **代表性的技术作品或贡献**
4. **对海燕党使命的理解与认可**
5. **GPG 公钥指纹**
6. **每周可投入的时间**

### 第二步：社区评估

- 公开讨论期：7 天
- 评估维度：技术能力、社区贡献、文化契合度
- 最终决策由现有核心团队投票产生

### 第三步：签署贡献者协议

通过评估的申请者需签署：

- **贡献者许可协议（CLA）**
- **核心团队工作章程**（参见 `team-charter.md`）
- **行为准则承诺**
