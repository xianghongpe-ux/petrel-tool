## 1. 概述

海燕党四层协议栈中，L3行动层负责在各国法律框架内注册实体组织。本指南聚焦**最容易注册的3个法域**，覆盖数字企业、协会、DAO三种形态。

### 1.1 选择标准

| 标准 | 说明 |
|------|------|
| **注册门槛低** | 无需当地居民董事、无需最低资本 |
| **远程完成** | 全流程在线，无需亲自到场 |
| **合规成本低** | 年维护费用合理，报税简单 |
| **结社自由高** | 法律对去中心化组织友好 |
| **认可度好** | 全球金融/法律体系广泛认可 |

### 1.2 前置条件

- 完成L0-L2协议栈部署
- DID身份系统就绪（见02-algorithm仓库）
- 至少3名核心成员的实名身份验证
- 社区治理提案通过（L3 Council 简单多数）

## 2. 方案一：爱沙尼亚数字居民（e-Residency）

> **最适合**：远程运营的数字组织、国际分布式团队  
> **实体形态**：欧盟有限责任公司（OÜ）  
> **透明度和合法度**：全球最高 — 欧盟正式注册企业

### 2.1 什么是e-Residency

爱沙尼亚是全球首个推出数字居民计划的国家。e-Residency 数字居民卡赋予非居民：
- 远程注册爱沙尼亚公司（OÜ = 类似LLC）
- 电子签名所有公司文件
- 全球在线管理公司（税务、银行、年报）
- 欧盟市场准入

### 2.2 注册步骤

```
步骤①  申请e-Residency数字居民卡
        ├─ 在线提交申请（https://e-resident.gov.ee）
        ├─ 缴纳申请费 €120（含背景审查）
        ├─ 前往爱沙尼亚驻外大使馆领取数字居民卡
        └─ 处理时间：2-4周

步骤②  注册公司（OÜ）
        ├─ 选择服务商（如 Xolo, LeapIN, e-Residency Hub）
        ├─ 最低注册资本 €2,500（无需实缴至银行账户）
        ├─ 提交公司章程（模板化，10分钟在线完成）
        ├─ 爱沙尼亚商业注册局登记（e-Business Register）
        └─ 处理时间：1-3个工作日

步骤③  开设银行账户
        ├─ 可选项：Wise Business / Revolut Business / LHV Bank
        ├─ 全部远程开户，无需到场
        └─ 处理时间：1-2周

步骤④  税务登记
        ├─ 爱沙尼亚税制：留存利润不征税，分红时征20%
        ├─ 在线提交零申报或年报（每年一次）
        └─ 会计服务：€30-100/月
```

### 2.3 费用明细

| 项目 | 费用 |
|------|------|
| e-Residency 申请费 | €120（一次性） |
| 公司注册费 | €265（一次性） |
| 最低注册资本 | €2,500（无需实缴） |
| 年度维护（会计+年报） | €500-1,200/年 |
| 虚拟办公室地址 | €50-150/年 |
| **首年总成本** | **≈ €900-1,700** |

### 2.4 时间线

| 阶段 | 预计时间 |
|------|----------|
| 数字居民卡申请 | 2-4周 |
| 公司注册 | 1-3个工作日 |
| 银行开户 | 1-2周 |
| **从零到运营** | **3-6周** |

### 2.5 合规要求

- ✅ 每年提交年报
- ✅ 保留会计记录（至少7年）
- ✅ 转让定价文档（如涉及关联交易）
- ⚠️ 如股东非EEA居民，需注意CRS报告
- ⚠️ 如果实际管理地在其他地方，可能产生税务常设机构

### 2.6 对海燕党的适配

爱沙尼亚OÜ可作为海燕党L3实体在欧洲的**法人载体**：
- 持有域名、服务器、智能合约所有权
- 签署合作协议、收取捐赠/会费
- 为社区提供法律保护屏障

## 3. 方案二：新加坡（Singapore）

> **最适合**：亚洲地区运营、需高金融信誉、计划募资  
> **实体形态**：公众公司担保有限（CLG — Company Limited by Guarantee）或 私人有限公司（Pte Ltd）  
> **透明度和合法度**：全球顶级金融中心，法律体系完善

### 3.1 为什么选择新加坡

新加坡是亚洲最受欢迎的注册地：
- 政治稳定、法律体系成熟（普通法系）
- 税收极低（企业所得税17%，初创免税计划）
- 无外汇管制
- 全球银行体系连通
- 对非营利组织友好的 CLG 结构

### 3.2 注册步骤

```
步骤①  确定实体类型
        ├─ 非营利/协会性质 → CLG（Company Limited by Guarantee）
        │   * 无需注册资本
        │   * 必须有至少3名董事
        │   * 必须有一名新加坡本地居民董事
        │   * 适合海燕党作为协会注册
        │
        ├─ 商业/营利性质 → Pte Ltd（私人有限公司）
        │   * 最低注册资本 SGD 1
        │   * 可100%外国人持有
        │   * 需要一名新加坡本地董事（可由服务商提供）
        │   * 适合海燕党作为商业实体注册
        │
        └─ 推荐：先注册CLG（非营利），再设Pte Ltd（商业）

步骤②  准备注册材料
        ├─ 组织名称（需ACRA审批，1-2个工作日）
        ├─ 公司章程（M&A文件）
        ├─ 董事/股东身份证明（护照+住址证明）
        └─ 注册地址（可由服务商提供）

步骤③  提交注册
        ├─ 通过 ACRA BizFile+ 在线提交
        ├─ 注册费：SGD 60-300（视类型）
        └─ 处理时间：1-3个工作日

步骤④  后续事项
        ├─ 开设银行账户（OCBC/DBS/UOB 远程开户可选）
        ├─ 公司印章
        ├─ 年度申报（AGM + Annual Return）
        └─ 税务：企业所得税申报（每年一次）
```

### 3.3 新加坡本地董事服务

CLG注册需要至少一名新加坡本地居民担任董事。解决方案：

| 方案 | 费用 | 说明 |
|------|------|------|
| 服务商提供提名董事 | SGD 1,200-3,000/年 | 仅限Pte Ltd |
| 本地合作伙伴担任 | 协商 | 需为海燕党成员或盟友 |
| 企业服务商全套 | SGD 500-2,000/年 | 含注册地址+秘书+报税 |

### 3.4 费用明细

| 项目 | CLG（非营利） | Pte Ltd（商业） |
|------|--------------|-----------------|
| 名称审批 | SGD 15 | SGD 15 |
| 注册费 | SGD 60-100 | SGD 60-300 |
| 注册地址（虚拟） | SGD 200-600/年 | SGD 200-1,200/年 |
| 公司秘书 | SGD 300-800/年 | SGD 300-800/年 |
| 会计/报税 | SGD 500-2,000/年 | SGD 800-3,000/年 |
| 提名董事（如需） | — | SGD 1,200-3,000/年 |
| **首年总成本** | **≈ SGD 1,100-3,500** | **≈ SGD 2,600-8,300** |

### 3.5 时间线

| 阶段 | 预计时间 |
|------|----------|
| 名称审批 | 1-2个工作日 |
| 公司注册 | 1-3个工作日 |
| 银行开户 | 1-4周 |
| **从零到运营** | **2-6周** |

### 3.6 合规要求

- ✅ 每年召开AGM（股东大会）
- ✅ 提交Annual Return（ACRA）
- ✅ 企业所得税申报（每年4月前）
- ✅ 保留会计记录
- ⚠️ CLG不能分配利润给成员
- ⚠️ Pte Ltd需做审计（年营收≥SGD 10M或资产≥SGD 10M）

### 3.7 对海燕党的适配

- **CLG** → 作为海燕党在新加坡的协会实体，接收捐赠、管理社区资金
- **Pte Ltd** → 作为商业运营实体，管理区块链节点、开发工具、提供服务

## 4. 方案三：美国怀俄明州DAO法案（Wyoming DAO LLC）

> **最适合**：纯粹的链上去中心化自治组织  
> **实体形态**：DAO LLC（去中心化自治组织有限责任公司）  
> **透明度和合法度**：全球首个专门为DAO立法的司法管辖区

### 4.1 什么是Wyoming DAO LLC

2021年7月，美国怀俄明州通过SF0038法案——全球首个为DAO提供法人地位的法案。DAO LLC拥有：
- 独立法人地位（可起诉/被起诉、持有资产、签合同）
- 有限责任保护（成员不因DAO债务承担个人责任）
- 可通过智能合约管理公司事务
- 成员信息可匿名（仅需一名组织者公开）

### 4.2 注册步骤

```
步骤①  准备材料
        ├─ 组织名称（必须以 DAO、LAO 或 DAO LLC 结尾）
        ├─ 注册代理人（Registered Agent — 怀俄明州地址，$50-300/年）
        ├─ 组织者信息（至少1人公开）
        ├─ 公司章程（Articles of Organization）— 需包含：
        │   * DAO声明（明确声明为去中心化自治组织）
        │   * 智能合约地址（可选但推荐）
        │   * 治理代币或投票机制说明
        │   * 解散条件（会员投票比例）
        └─ 运营协议（Operating Agreement）— 可不上传但建议保留

步骤②  提交注册
        ├─ 通过 Wyoming Secretary of State 在线提交
        ├─ 注册费：$102（在线提交）
        └─ 处理时间：1-2个工作日（加急1小时）

步骤③  获取EIN（雇主识别号）
        ├─ 通过 IRS 在线申请（SS-4表格）
        ├─ 完全免费
        └─ 处理时间：即时

步骤④  银行账户与税务
        ├─ 可选：开设美国商业银行账户（需EIN + 注册文件）
        ├─ 推荐 Mercury / Relay 等远程开户友好银行
        └─ 税务：Wyoming无州所得税（零州税），联邦所得税按LLC规则
```

### 4.3 费用明细

| 项目 | 费用 |
|------|------|
| 注册费 | $102（在线）/ $100（邮寄） |
| 注册代理人 | $50-300/年 |
| 年度报告（Annual Report） | $62/年（在线提交）/ $52/年（邮寄） |
| EIN申请 | 免费 |
| 银行开户 | 免费 |
| **首年总成本** | **≈ $200-500** |

### 4.4 时间线

| 阶段 | 预计时间 |
|------|----------|
| 名称查重 | 即时 |
| 注册提交 | 1-2个工作日 |
| EIN获取 | 即时 |
| 银行开户 | 1-3周 |
| **从零到运营** | **1-4周** |

### 4.5 合规要求

- ✅ 每年提交年度报告（Annual Report）— $62
- ✅ 保持注册代理人有效
- ⚠️ 如果被视为"协会"，可能需报Form 1120
- ⚠️ 如果仅持有加密货币且不交易，税务处理较简单
- ⚠️ 必须明确会员的投票权和退出权
- ⚠️ DAO LLC 解散后资产的分配规则必须提前在运营协议中明确

### 4.6 Wyomming DAO LLC vs. 其他州

| 特性 | 怀俄明 | 特拉华 | 田纳西 | 佛蒙特 |
|------|--------|--------|--------|--------|
| 专门DAO法 | ✅ 有 | ✅ 有 | ✅ 有 | ✅ 有 |
| 注册费 | $102 | $89(+特许税$300) | $100 | $125 |
| 年费 | $62 | $300 | $100 | $175 |
| 州所得税 | 0% | 8.7% | 6.5% | 6% |
| 隐私性 | 好 | 中 | 好 | 中 |
| **推荐度** | **⭐⭐⭐** | ⭐⭐ | ⭐⭐ | ⭐ |

### 4.7 对海燕党的适配

Wyoming DAO LLC是海燕党L3层**纯粹的链上治理实体**的最佳选择：
- DAO章程可映射海燕党协议中的治理机制
- 智能合约地址直接关联链上投票
- 无需披露成员身份
- 配合 did:web 可建立链上身份对实体身份的映射

## 6. 通用合规清单

所有注册方案均需完成以下合规事项：

### 6.1 注册前

- [ ] 社区治理提案通过（L3 Council 多数决）
- [ ] 选定注册法域（基于合规矩阵评分 ≥ 0.60）
- [ ] 确定实体类型（协会/基金会/有限公司/DAO）
- [ ] 准备核心章程（draft v1.0 — 可参考 01-constitution 仓库）
- [ ] 完成至少3名核心成员KYC
- [ ] 预约注册代理人/服务商

### 6.2 注册中

- [ ] 名称查重与审批
- [ ] 提交注册文件
- [ ] 获取注册证书
- [ ] 开立银行账户
- [ ] 税务登记
- [ ] 获取EIN/税号

### 6.3 注册后（持续）

- [ ] 年度报告提交（Annual Report）
- [ ] 税务申报（企业所得税/增值税）
- [ ] 会计记录存档
- [ ] 董事/成员变更更新
- [ ] 注册地址/代理人续费
- [ ] 链上锚定注册证书（IPFS + 区块链存证）

### 6.4 海燕党专属

- [ ] 在实体章程中嵌入创世铭文（政党名称/英文名称/创始人）
- [ ] 建立实体治理与链上治理的桥接机制
- [ ] DID身份与法人身份关联（did:web 解析）
- [ ] 定期向社区披露L3层运营报告
- [ ] 注册信息变更时同步更新合规矩阵
